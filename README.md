# Retail Flow

I am building a BTech DBMS project called:

"NextGen Online Retail and Order Management Platform"

IMPORTANT:

My actual database is PostgreSQL and I manage it using pgAdmin 4.

Do NOT use MySQL or MySQL Workbench.

For this step, ONLY build the FRONTEND.

Use React and JavaScript.

Create a professional but simple student-project interface with:

1. Dashboard

2. Customers

3. Products

4. Categories

5. Inventory

6. Cart

7. Orders

8. Payments

9. Delivery

10. Reviews

11. Reports

The Dashboard should provide navigation to all modules.

Create forms for:

- Add Customer

- Add Product

- Add Category

- Add Inventory/Stock

Create tables/lists for displaying:

- Customers

- Products

- Inventory

- Orders

- Payments

- Delivery

IMPORTANT:

For now, create the frontend structure and UI only.

Do NOT create a fake database.

Do NOT invent real database data.

Keep the frontend ready to connect to a backend API later.

Make the UI clean, responsive and suitable for a BTech DBMS project.

Do not work on the backend yet.
